The ML underneath

Real graph analytics — the agents act on math, not vibes.

  • Louvain community detection — auto-discovers QM clusters, no k needed (Blondel 2008)
  • Betweenness centrality — true SPOFs, not just busy nodes (Freeman 1977)
  • Shannon entropy — quantifies hub-and-spoke fragility (Shannon 1948)
  • Kruskal MST + reachability pruning — provably minimal channel set
  • Kernighan–Lin bisection — clean regional split points

Every number an agent acts on traces to a named, citable algorithm. Classical algorithms compute the features; Gemini reasons over them — the right tool at every layer.
